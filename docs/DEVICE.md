# 设备与隐私

- 最低 Android 6.0 / API 23。4K、HEVC 与 HDR 播放受设备解码能力和线路配置影响。
- 开机播放取决于 Android 系统和厂商策略。首次安装需先打开应用并添加频道。无障碍开机助手和恢复辅助由用户自行授权。无障碍服务用于识别前台应用包名与屏幕状态，不读取窗口内容。可选通知监听服务用于系统恢复，不收集通知内容。
- 频道、EPG、收藏与播放诊断存于本机。访问订阅、媒体、节目单和 M3U 附带的在线台标时，会向对应服务发起网络请求。
- 扫码配对在电视上临时开启带随机令牌的局域网 HTTP 服务。配对页关闭或五分钟后失效。请在信任的同一网络使用。诊断导出由用户主动触发，并隐藏 URL 路径、参数与请求头。
- 小米 L50M5-AD 和 Sony BRAVIA 仍需逐机验证开机、待机和长时间播放。
